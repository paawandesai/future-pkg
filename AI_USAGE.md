# AI usage register

Every artifact in this repository that a model generated, and how far it has been checked.
"Claude" here means Anthropic's Claude working through Claude Code on the paid API. The
authoring model's version isn't recorded in the repository: model identifiers stay out of
committed files, commits and merge requests by project rule. The runtime models are
configuration (`.env.example`, `docs/latency.md`).

## At runtime

| Output | Model role | Guardrail |
|---|---|---|
| Intent from the coach's request | Fast model, structured output | A deterministic scan unions in any injury or equipment mention the model missed |
| Exercise selection and order | Main model picks ids from a filtered list | Ids not offered are dropped; the model never sees excluded exercises or writes edges |
| Copilot answers and charts | Main model with read-only tools | Member fixed by the server; chart data filled by the server; answers carry an AI disclosure |
| Congratulation draft | Main model | Labelled "Drafted by AI for the coach to review and edit. Not sent."; no send path exists |
